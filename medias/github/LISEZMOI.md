# Images pour GitHub et les réseaux

Préparées le 07/11/2026, pour l'ouverture d'Armana à toute la France.

| Fichier | À quoi il sert |
|---|---|
| `social-preview-github-1280x640.png` | Image d'aperçu du dépôt, quand on partage son lien (taille recommandée par GitHub). |
| `logo-fond-bleu-512.png` | Logo sur fond bleu Armana, carré : avatar, profil de réseau social. |
| `icone-application-512.png` | L'icône de l'application installée. |
| `logo-masques-288.png` | Les masques seuls, fond transparent. |

## Mettre l'aperçu sur GitHub (deux clics, impossible en ligne de commande)

1. https://github.com/22eme-Arkane/armana → **Settings**.
2. Section **Social preview** → **Edit** → **Upload an image…** →
   `social-preview-github-1280x640.png`.

Le logo du README, lui, s'affiche tout seul : il pointe vers
`public/icons/armana-logo-grand.png`.
